## Сайты судов

Список сайтов судов взят у
[tochno-st/sudrfscraper](https://github.com/tochno-st/sudrfscraper/blob/master/src/main/resources/config/config_sudrf.json).

Для большинства из **2270** сайтов сохранено расписание судебных заседаний с января 2021 по
август 2025.

Есть аномалии в форматах запросов и поведении сайтов, поэтому данные могут
быть неполными.

Из расписаний выбраны дела содержащие строчку _158_ в описании. Таких
оказалось **927001**. По ним выгружена подробная информация, включающая тексты
решений. Из-за разнообразия форматов представления этой информации в HTML, пока
не удалось их единообразно распарсить.
